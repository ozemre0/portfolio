# Portfolio

This is a Flutter portfolio website showcasing my projects and applications.

## Features

- Responsive design for all screen sizes
- Multi-platform support (Web, iOS, Android, Windows, macOS, Linux)
- Internationalization (i18n) support
- Modern UI with Material Design 3

## Projects Showcased

- Hit Archery - Training and performance tracking application
- Hit Archery Score - Competition management platform
- Neon Show - Synchronized light show application
- Hosting & SSL Management - Client project for web hosting provider

## Technologies

- Flutter
- Supabase
- Cloudflare Workers
- Offline-First Architecture

## Getting Started

```bash
flutter pub get
flutter run
```
