# GitHub Pages Deployment Instructions

## Setup Steps

1. Go to Repository Settings → Pages
2. Under "Source", select **"Deploy from a branch"**
3. Select:
   - Branch: `main`
   - Folder: `/docs`
4. Click **Save**

## Site URL

After deployment, your site will be available at:
- https://ozemre0.github.io/portfolio/

## Troubleshooting

If you see a 404 error:
1. Make sure GitHub Pages is enabled in Settings → Pages
2. Verify that the `docs` folder contains `index.html`
3. Check that the branch is set to `main` and folder is `/docs`
4. Wait 1-2 minutes after saving settings for the site to deploy
